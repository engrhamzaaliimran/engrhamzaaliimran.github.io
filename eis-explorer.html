What you are exploring

Real spectra

Source HDF5 measurements from the open TFT-IS repository. Select only measured conditions; no interpolated mixtures are presented as observations.

Original fitting workflow

EMG fitting uses the supplied Python function, bounds, initialization, and SciPy settings. Three temperatures contribute four parameters each to a 12-dimensional feature vector.

Transparent interpretation

PCA is an unsupervised projection, not a classifier or an accuracy score. Coordinates remain fixed when you select or highlight a condition.

Data processing and reproducibility

Displayed −Im(Z) = −|Z| sin(phase), following the notebook’s plotting convention. Real impedance = |Z| cos(phase). Phase is stored in radians and displayed in degrees. Fitting uses the complete source frequency arrays; curves displayed here are sampled to at most 201 original frequency points for responsive interaction.

At each condition, sweep indices are aligned across temperatures as in the notebooks; this does not imply simultaneous acquisition. Unsuccessful or nonfinite fits are excluded from PCA. Files that cannot form a complete temperature set remain available for spectrum inspection.
